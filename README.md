# Garden Diary

Home Assistant add-on for the veggie beds and fruit trees at Antrim. Logs sowing, planting out, harvests, feeding, problems and tree sprays, keeps every season side by side, and works out what to do this week from the greenhouse, seed-tray and outside sensors.

Local add-on: copy this folder to `/local_apps/garden_diary` on the Home Assistant box and install it from Settings > Add-ons > Add-on store > Local.
